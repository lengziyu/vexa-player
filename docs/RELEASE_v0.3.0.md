Windows x64 开发版。下载 **Vexa-Player-0.3.0-Windows-x64.exe** 运行安装；`SHA256SUMS.txt` 可校验完整性。

### 这次更新

- 新增 X / Twitter 单条原生视频下载：粘贴帖子链接、选择视频和画质、排队下载、取消/重试、完成后加入视频库。支持多视频帖子分别选择。
- X 登录为可选功能。局部面板说明哪些内容可能需要登录、账号会话的权限，以及本机加密保存、使用和清除方式；可在官方窗口登录或主动导入 X Cookie 文件，不自动读取其他浏览器账号。
- 播放墙上限从 16 提高到 32，新增 20/24/28/32 路预设；单画面与统一控制增加 3×、5× 倍速。
- 16 路起显示轻量资源提醒，持续掉帧时优先显示实际数量，可一键暂停非主画面。32 路短测观察到掉帧，不承诺所有设备长期流畅。
- 倍速、排序、筛选、换片间隔、下载连接和画质选择统一为自定义菜单；复选框和折叠区域同步美化，支持深浅主题、键盘、全屏和减少动效。
- 登录操作收进按钮旁的小面板，移除顶栏没有实际账号功能的头像。
- 修复全屏控件自动隐藏时，焦点离开倍速按钮可能导致控件立即重新出现的问题。

### 安装包与下载组件

保留之前的安装包压缩与资源精简方案，本地导入、媒体探测和播放仍可离线使用。X 下载首次使用需主动安装约 17 MiB 的固定版本官方 yt-dlp 组件，并进行大小和 SHA-256 校验；该可选组件不计入主安装包体积，也不自动更新。

### 验证范围

完成单元/集成检查、打包程序的桌面播放回归、32 路容量及高倍速检查、合成凭据的登录面板与系统加密检查，以及真实公开 X 样本的解析、下载、入库和播放。安装包检查包含内嵌档案解压/CRC、运行资源和媒体工具哈希、许可证保留及测试数据/登录文件排除。具体数量、安装包大小和 SHA-256 见随附的 `test-summary.json`。

X 登录完整账号流程、受限内容的可下载性、不同网络与地区仍受 X 和账号实际权限影响；不承诺所有帖子均可下载。下载任务不跨重启保存。32 路测试为短时低复杂度 1080P 样本，不能替代长期高码率、多种显卡和复杂运动内容的性能验收。macOS 安装包、本机安装器实际安装/卸载及正式证书签名未验收。
