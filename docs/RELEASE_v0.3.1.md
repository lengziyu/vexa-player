Windows x64 开发版。下载 **Vexa-Player-0.3.1-Windows-x64.exe** 运行安装；`SHA256SUMS.txt` 可校验完整性。

### 这次更新

- 视频库增加工具栏“全选”按钮，选择当前筛选结果中的全部视频，包括尚未滚动加载的条目；支持取消选择。
- 播放墙统一音量旁可切换“仅选中 / 全部声音”，支持多个画面同时发声，继续遵循全局和独立音量、静音设置。
- 播放中可展开选片侧栏，搜索、筛选收藏、分页浏览或导入视频，直接添加或替换指定画面；其他视频继续播放，全屏内也能操作。
- 侧栏“正在播放”可定位或移出画面；移出后 8 秒内可撤销，恢复原位置、进度和独立设置，不删除磁盘文件。
- 默认关闭播放结束自动换片和定时换片。换片、横竖比例变化时保持格子位置与大小；手动重排、增减画面、切换布局或调整窗口时重新适配。
- 新增“重新排布画面”按钮；全屏资源提示浮在播放区域上，不再挤压画面或触发重排。

### 升级说明

直接安装新版继续使用原有本地视频库和偏好。**已有用户保存的自动换片设置会保留**；如果升级后仍自动切换视频，请在“偏好设置”关闭“播放结束后自动换片”，并将“定时自动换片”设为关闭。新建偏好默认均为关闭。

### 验证与下载

安装包保持约 127 MiB。完成单元检查及最终打包程序的桌面交互、32 路与高倍速、X 登录面板、公开样本下载和媒体编码回归。安装包内容、内嵌归档解压/CRC、媒体工具哈希和测试数据排除均有检查；具体结果、大小和 SHA-256 见随附 `test-summary.json`。

32 路为短时低复杂度样本检查，流畅程度取决于设备和素材；实际安装/卸载、正式签名、真实 X 账号登录及长时间高负载尚未验收。macOS 安装包暂未发布。
