# Vexa UI 概念预览

仅用于视觉与交互评审，独立于桌面产品开发。直接打开 `index.html` 即可使用，无需安装依赖。

- 石墨黑与雾紫配色，可在偏好设置切换鼠尾草绿、暖沙金。
- 智能、主次、网格布局，画面增删、拖拽交换、锁定、随机换片与聚焦放大。
- 视频库筛选、多选创建播放墙、收藏、搜索、快捷键、隐私遮罩和减少动态效果。
- 可选择本地视频，在浏览器支持的格式范围内临时真实播放；不上传文件。

示例库使用静态风景照片及模拟时长、进度，已在界面标示。此原型不包含真实目录扫描、FFmpeg、SQLite、Electron 或原生播放器内核。示例信息与收藏仅驻留页面内存；主动“保存布局”只将布局、数量和适配方式写入浏览器本地存储。

图片通过 Unsplash 图片服务取得，已保存在 `assets/` 中。页面运行时不需要联网，不加载远程字体或脚本。

设计评审可重点体验：主次 / 智能切换、添加到 5 个画面、悬停按 R 换片、锁定后批量随机、双击放大、Space 全部暂停、偏好设置、隐藏并静音。
